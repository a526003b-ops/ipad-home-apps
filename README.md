# iPad Home Apps

Private-on-device **Diary** and **Sing** web apps.

## On the iPad

1. Open Safari (not Chrome).
2. Diary: https://a526003b-ops.github.io/ipad-home-apps/diary/
3. Tap Share → Add to Home Screen → leave **Open as Web App** on → Add.
4. Repeat for Sing: https://a526003b-ops.github.io/ipad-home-apps/sing/

Entries and high scores stay in IndexedDB on that iPad. Use Diary → Export for a backup file.
