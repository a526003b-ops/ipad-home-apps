# iPad Home Apps

Diary, Sing, and Wallpaper. Local-only.

## On the iPad

1. Open Safari (not Chrome).
2. Add each to the Home Screen with **Open as Web App** on:
   - https://a526003b-ops.github.io/ipad-home-apps/diary/
   - https://a526003b-ops.github.io/ipad-home-apps/sing/
   - https://a526003b-ops.github.io/ipad-home-apps/wallpaper/

Wallpaper cannot be the system Lock/Home background and stay interactive. Install it as its own full-screen app instead.
